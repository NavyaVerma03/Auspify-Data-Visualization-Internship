## 📊 Project Tasks & Analysis

### ✅ Task 01 — Data Cleaning & Chart Preparation

**Objective:** Prepare a clean and structured Netflix dataset for reliable analysis.

**Work Performed:**
- Inspected the original dataset.
- Identified and handled missing values.
- Checked duplicate records.
- Repaired one malformed/split record.
- Prepared cleaned data.
- Created Pivot Tables and charts.
- Identified key data quality findings.

**Key Results:**

| Metric | Result |
|---|---:|
| Cleaned Records | 8,790 |
| Duplicate IDs | 0 |
| Malformed Records Repaired | 1 |

📁 [Explore Task 1 Screenshots](Task_Screenshots/Task_1_Data_Cleaning/)

---

### ✅ Task 02 — Netflix Content Distribution Dashboard

**Objective:** Analyze the distribution of Movies and TV Shows available in the Netflix dataset.

**Work Performed:**
- Analyzed Movies and TV Shows.
- Compared content types.
- Created a Pie Chart.
- Created a Column Chart.
- Designed a content distribution dashboard.
- Highlighted key takeaways.

**Key Results:**

| Content Type | Total Titles | Percentage |
|---|---:|---:|
| Movies | 6,126 | 69.7% |
| TV Shows | 2,664 | 30.3% |
| **Total** | **8,790** | **100%** |

📁 [Explore Task 2 Screenshots](Task_Screenshots/Task_2_Content_Distribution/)

---

### ✅ Task 03 — Country-Wise Content Analysis

**Objective:** Explore the geographical distribution of Netflix content across countries.

**Work Performed:**
- Analyzed country-wise content distribution.
- Identified the Top 10 Countries.
- Created a Top 10 Countries Bar Chart.
- Added a Country Filter/Slicer.
- Prepared a country-wise analysis table.
- Highlighted geographical insights.

📁 [Explore Task 3 Screenshots](Task_Screenshots/Task_3_Country_Wise_Analysis/)

---

### ✅ Task 04 — Netflix Release Trend Visualization

**Objective:** Analyze Netflix content release patterns over the years.

**Work Performed:**
- Analyzed content by release year.
- Created a Release Trend Line Chart.
- Prepared a Release Year Pivot Table.
- Identified growth patterns.
- Highlighted the peak release year.

**Key Findings:**

| Metric | Result |
|---|---:|
| Total Titles Analyzed | 8,790 |
| Peak Release Year | 2018 |
| Titles in Peak Year | 1,146 |
| Titles Released (2015–2021) | 6,207 |
| Percentage (2015–2021) | 70.6% |

📁 [Explore Task 4 Screenshots](Task_Screenshots/Task_4_Release_Trend/)
